about=QGIS 4 plugin that adapts AUTHENIX and STAplus pieces from the STAplus-SCK-App. It signs in with a public AUTHENIX client using QGIS OAuth2 (authorization code + PKCE, system browser, loopback redirect), extracts the access token for STAplus HTTP and MQTT, reads a Smart Citizen Kit over serial, and publishes ObservationGroups. Plugin messages appear under the "STAplus SCK" tab in the QGIS Log Messages panel.
